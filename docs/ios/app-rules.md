iOS app rules

Project

- SwiftUI app, iPhone, iOS 17 or newer. Bundle id net.vrizo.mozol, display name MOZOL, Apple team 5X3V5CCN2N.
- Swift 6 language mode. The app target uses MainActor as the default isolation.
- The Xcode project is generated by xcodegen from ios/project.yml. Never hand-edit the pbxproj.
- Pure logic lives in the MozolCore Swift package (ios/MozolCore). It imports no UIKit and no framework with side effects, so `swift test` runs it on any Mac. The app target holds adapters (network, notifications, storage) and UI.
- Persistence on the phone: SwiftData. Secrets and identity: Keychain.
- SwiftUI previews live in ios/Mozol/UI/Previews/, all inside #if DEBUG. Sample data goes in PreviewData.swift, not inline. Previews never touch the network.

Network

- The base URL is https://mozol.vrizo.net (API routes under /api/, web pages on other paths), set in ios/Mozol/App/Config.swift. It can be overridden at run time with the UserDefaults key `mozol.apiBaseURL` (a launch argument `-mozol.apiBaseURL <url>` sets it). The simulator points at the local worker this way.
- Every request carries `X-Request-Id` from `RequestID.make()` in MozolCore, and the app logs it under the `api` category on the way out and on the way back.
- A failed request is retried only where the spec says so. No silent retries and no hidden fallbacks.

Logging

- The app logs through MozolCore/Log.swift only: `os.Logger`, subsystem `net.vrizo.mozol`, a closed set of categories (../logs/layout.md). No print, no NSLog.
- Logs never contain the user's learning content — only ids, counts, timings and error codes.

UI and accessibility

- Every interactive control has an accessibility label; reuse the visible string.
- Decorative images get .accessibilityHidden(true).
- A row built from several text fragments is one accessibility element (.accessibilityElement(children: .combine)).
- A state change is exposed to VoiceOver, not only drawn: .accessibilityValue for work in progress, .disabled() for disabled (never opacity alone).
- Text scales with Dynamic Type. A fixed size is allowed only through @ScaledMetric(relativeTo:), so larger settings still scale.
- Colors, type, shape and components follow ../web/design-system.md. The SwiftUI tokens and components live in ios/Mozol/UI/DesignSystem/; screens use them, never raw values.
- The app is light only (UIUserInterfaceStyle Light), like the web app. The accent color is ink, #111111.
- Sans text is Helvetica Neue through Font.sans (custom font relative to a text style, so it scales with Dynamic Type). Mono text is the system monospaced font.
- System navigation bars, the tab bar and toolbar buttons stay native; they are tinted ink and use Helvetica Neue titles. Everything inside a screen uses the design-system components: square corners, 2 px ink borders, hard shadows.
- Copy rules: ../rules/ui-copy.md.
- Launch splash (ios/Mozol/UI/LaunchSplash.swift): the final frame of the landing intro, the word MOZOL drawn with characters, floats for 1.4 s; then the characters scatter to the screen edges in about 1.1 s while the app fades in. With Reduce Motion on, the word stands still and only fades. The splash is decorative: hidden from VoiceOver, it never takes touches.

Features: messages.md (silent push, fetching, Inbox), reminders.md (writing to Apple Reminders), permissions.md, shortcuts.md. Sign-in: ../product/accounts.md. TestFlight: ../deployment/testflight.md.

DEBUG launch arguments, for tests and local runs only:

- `-uitest.reset` deletes the session, the Inbox, the cursor and the onboarding flag at launch.
- `-uitest.signedIn` starts signed in as uitest@example.com with the placeholder token.
- `-uitest.skipPermissions` marks the Permissions screen as shown.

A Debug build also takes silent push payloads from scripts/sim-push.sh (testing.md).

Testing: testing.md.
