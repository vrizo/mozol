B01 Foundation: workspace, worker skeleton, health, logging, local stack

Track: backend. Depends on: nothing. Next: B02.

Goal

A pnpm workspace with three packages (web, worker, shared), a Cloudflare Worker that answers GET /api/health, logs one JSON line per request and serves the web build, a D1 database bound to it, a passing test, and a local stack that starts on this Linux machine.

Read first

- AGENTS.md, plan/README.md
- docs/architecture/overview.md, docs/backend/worker.md, docs/deployment/infrastructure.md, docs/logs/layout.md, docs/rules/dependencies.md
- skills/local-stack/SKILL.md, skills/reading-logs/SKILL.md
- scripts/lib/run-dir.sh, scripts/dev-worker.sh, scripts/start-all.sh, scripts/stop-all.sh, scripts/deploy-worker.sh
- package.json, pnpm-workspace.yaml, biome.json, web/package.json, web/vite.config.ts

Do

1. Install pnpm in the version of package.json "packageManager": `npm install -g pnpm@<version>`. Check `pnpm --version`.
2. pnpm-workspace.yaml: packages web, worker, shared. Keep minimumReleaseAge.
3. shared/: package "shared" (private, type module, `"exports": { ".": "./src/index.ts", "./fixtures/*": "./fixtures/*" }`, no build step), tsconfig (strict, like web/tsconfig.json without DOM), dependency zod. src/index.ts exports HealthResponse = z.object({ ok: z.literal(true) }). B02 adds everything else.
4. worker/: package "worker" with scripts test (vitest run), typecheck (tsc --noEmit), dev (wrangler dev --port 8790). Dependencies: hono, zod, shared (workspace:*). Dev dependencies: wrangler, vitest, @cloudflare/vitest-plugin, @cloudflare/workers-types (or types generated by `wrangler types`), typescript. Pin versions at least 72 hours old.
5. worker/wrangler.jsonc:
   - name mozol-api, main src/index.ts, a current compatibility_date, compatibility_flags ["nodejs_compat"], observability enabled.
   - routes: the custom domain mozol.vrizo.net.
   - assets: directory ../web/dist, binding ASSETS, not_found_handling single-page-application, run_worker_first ["/api/*"].
   - d1_databases: binding DB, database_name mozol, the real database_id, migrations_dir migrations.
   - vars: APP_ORIGIN https://mozol.vrizo.net, ANALYSIS_MODE claude, ANALYSIS_MODEL claude-opus-5-5, ANALYSIS_EFFORT high, PUSH_MODE apns.
6. The D1 database: run `pnpm exec wrangler d1 list` with the token from .env. If a database named mozol exists, use its id; otherwise `pnpm exec wrangler d1 create mozol`. Read the token the way scripts/deploy-worker.sh does (env_value in scripts/lib/run-dir.sh) and never print it. Create worker/migrations/ (empty; B03 adds 0001).
7. worker/src/:
   - index.ts: the Hono app. GET /api/health answers HealthResponse. Any other /api/* path answers 404 `{ "error": "not_found" }`. It exports the default fetch handler.
   - log.ts: `log(rid, evt, fields)` prints one JSON object per line with rid first; errors add "level":"error" and go to console.error. Never log bodies.
   - Request id middleware: take X-Request-Id when it is 12 lowercase hex characters, otherwise make one; put it on the context and on the response header; when the response is done, log `{ rid, evt: "req", method, route, status, ms }`.
   - errors.ts: an ApiError (status, code, optional issues) and one error handler: ApiError → its status and `{ error }`; a zod error from request validation → 400 validation_failed with issues (path joined with dots, zod code); invalid JSON → 400 bad_json; anything else → 500 internal, logged with level error and the error message.
   - env.ts: the Env type of all bindings and variables.
8. worker/vitest.config.ts with @cloudflare/vitest-plugin reading wrangler.jsonc. worker/test/health.test.ts: 200 `{"ok":true}`; a valid X-Request-Id comes back unchanged; a missing or invalid one is replaced by 12 hex characters; GET /api/nope answers 404 not_found.
9. scripts/dev-worker.sh, before it starts wrangler:
   - writes worker/.dev.vars (mode 600) with APP_ORIGIN=http://localhost:5190, ANALYSIS_MODE=fixture (claude when MOZOL_ANALYSIS=claude is set), PUSH_MODE=log, and ANTHROPIC_API_KEY when .env has it (read the single key, never print it);
   - builds the web app when web/dist is missing (wrangler needs the assets folder).
   Keep everything else the script does. Check that .gitignore covers .dev.vars (it does: `.dev.vars`).
10. biome.json: include worker/** and shared/**, excluding generated files, .wrangler, dist and node_modules. Root scripts: `pnpm lint` passes; add `typecheck` and `test` scripts that run in every package.
11. Run the local stack on this machine: `scripts/start-all.sh --no-app`. When a script breaks on Linux, fix it so it works on both Linux and macOS, and list each fix in the report.

Checks

- `pnpm install` (timeout 5 minutes).
- `pnpm lint`, `pnpm -r typecheck`, `pnpm --filter worker test`.
- `scripts/start-all.sh --no-app` prints "stack is up".
- `curl -fsS -D - http://localhost:8790/api/health` shows `{"ok":true}` and an X-Request-Id header.
- `curl -fsS http://localhost:5190/api/health` (through the Vite proxy) shows `{"ok":true}`.
- `grep '"evt":"req"' logs/current/worker.log | tail -c 1000` shows the request lines with rid.
- `scripts/stop-all.sh`.
- `scripts/deploy-worker.sh --check` passes.

Out of scope

Tables (B03), any route other than health, deploying.
